# Composite Carrier GitHub Pages Site

A static multi-page website for the Cal Poly Composite Carrier Senior Project. The site uses the project team's Composite Carrier logo and a green-and-gold visual system based on Cal Poly's primary brand colors.

## Files
- `index.html` — project overview and prominent team logo
- `design.html` — final design and subsystem explanation
- `manufacturing.html` — fabrication process
- `verification.html` — verification test summary
- `gallery.html` — project imagery and team logo
- `acknowledgments.html` — team, sponsors, and official project record
- `styles.css` — shared responsive green-and-gold styling
- `assets/composite-carrier-logo.png` — transparent, web-optimized team logo
- `assets/composite-carrier-favicon.png` — browser icon generated from the team logo
- `assets/` — project images extracted from the final report

## Theme colors
- Poly Green: `#154734`
- Mustang Gold: `#BD8B13`
- Supporting golds: `#F2C75C` and `#F8E08E`

## Publish with GitHub Pages
1. Create a new GitHub repository, such as `composite-carrier`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide the public Pages URL after deployment.

No build tools or external dependencies are required.
