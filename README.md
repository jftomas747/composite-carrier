# Composite Carrier GitHub Pages Site

A static multi-page website for the Cal Poly Composite Carrier Senior Project, designed in a visual style similar to the referenced B-2 Spirit project website while using original project content and imagery from the Composite Carrier report.

## Files
- `index.html` — project overview
- `design.html` — final design and subsystem explanation
- `manufacturing.html` — fabrication process
- `verification.html` — verification test summary
- `gallery.html` — project imagery
- `acknowledgments.html` — team and sponsors
- `styles.css` — shared responsive styling
- `assets/` — images extracted from the project report

## Project report

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `composite-carrier`).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide the public Pages URL after deployment.

No build tools or external dependencies are required.
